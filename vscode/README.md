# Solacula Dark

Tema escuro que mistura **Solarized Dark** e **Dracula**: o fundo azul-petróleo e os azuis/cianos do Solarized com os vermelhos, roxos, rosas e tons brilhantes do Dracula.

Usa a mesma paleta do color scheme **Solacula Glass** para Windows Terminal, disponível no [repositório](https://github.com/rezendesfelipe/solacula-theme), para que editor e terminal fiquem iguais.

## Paleta

| Papel | Cor | Origem |
|---|---|---|
| Fundo | `#142A36` | mistura Solarized base03 + Dracula bg |
| Texto | `#D4DCD6` | — |
| Palavras-chave / operadores | `#FF79C6` | Dracula |
| Funções | `#6CCF60` | mistura |
| Strings | `#E6C35C` | mistura |
| Números / constantes | `#BD93F9` | Dracula |
| Tipos / chaves JSON-YAML | `#8BE9FD` | Dracula |
| Parâmetros | `#FFB86C` (itálico) | Dracula |
| Comentários | `#6272A4` (itálico) | Dracula |
| Built-ins | `#2AA198` | Solarized |

## Ativar

`Ctrl+K Ctrl+T` → **Solacula Dark**.
